# Security Policy

## Supported status

This repository is a research prototype. It is not intended for production deployment without review, hardening, and validation.

## Reporting a concern

If you find a security or privacy issue, please open a GitHub issue with a clear description. Avoid posting sensitive data, access tokens, private datasets, or personally identifiable information.

## Data handling guidance

Human-AI collaboration studies may involve participant data. Before using this repository in real studies:

- Remove personal identifiers where possible.
- Store consent forms separately from experiment logs.
- Avoid committing private study data.
- Follow institutional review and ethics requirements.
- Clearly document how participant data is collected and used.

## Responsible AI guidance

Do not use prototype metrics as final evidence that an AI system is safe, trustworthy, or effective. Metrics should be interpreted together with qualitative analysis, expert review, and study limitations.
