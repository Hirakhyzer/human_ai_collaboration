# Contributing

Thank you for considering a contribution to Human-AI Collaboration Lab.

## Good contribution areas

- New human-AI collaboration scenarios.
- New trust, risk, or explainability metrics.
- Better evaluation methodology documentation.
- Tests for existing utilities.
- Dashboard or visualization prototypes.
- Research templates for empirical studies.

## Contribution workflow

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Add or update tests when needed.
5. Open a pull request with a clear explanation.

## Research quality expectations

When adding study materials or metrics, explain:

- What the metric measures.
- What assumptions it makes.
- What it does not prove.
- How it should be interpreted responsibly.

## Code style

Prefer readable Python with type hints and small functions. Keep the prototype transparent so researchers can inspect how each score is computed.
